# PROJETOS

## Histórico de preços do iPhone 17 Pro Max

O arquivo [`historico_precos_iphone.csv`](historico_precos_iphone.csv) contém uma linha por oferta encontrada, com data da coleta, loja, produto, preços em USD e BRL e links de referência.

O GitHub Actions atualiza esse arquivo diariamente às 09:00 no horário de Brasília. Para usar no Google Sheets, abra uma planilha, selecione **Arquivo > Importar > Fazer upload** e escolha o CSV.

Colunas disponíveis: `Data`, `Modelo`, `Produto`, `Loja`, `Preco_USD`, `Preco_BRL`, `Codigo`, `Link_Produto` e `Link_Loja`.
